**Implements:** `01. Architecture Overview.edd.md`, Testing & Rollout Plan step 1.
**TL;DR:** Create the monorepo directory structure, per-directory licenses, and
empty buildable project shells for desktop/iOS/Android so later slices have
somewhere to land.

---

## Scope

**In:**
- `/desktop` — Tauri + Svelte project shell (EDD §5.5 frontend decision).
- `/ios` — blank SwiftUI app shell, min deployment target iOS 17 (PRD Decisions).
- `/android` — blank Kotlin/Compose app shell.
- `/protocol` — empty directory + a one-line placeholder noting it's populated at
  roadmap step 6 (Protobuf codegen prototype).
- Per-directory `LICENSE` files: GPLv3 (`/desktop`), MIT (`/ios`, `/android`,
  `/protocol`) — per EDD §4/§7 licensing.

**Out:**
- Any real UI (roadmap step 2).
- Any protobuf schema (roadmap step 6).
- CI/build pipelines beyond each scaffolding tool's own defaults.
- Deep Android config (exact min API level is an open PRD decision, not this
  slice's job to fix).

> **Rule for agent:** stay inside this scope. If something out of scope blocks
> you, stop and flag it — don't silently expand scope to route around it.

## Files to Touch

- `/desktop/` — create — Tauri app via its CLI, Svelte + TypeScript template.
- `/desktop/LICENSE` — create — GPLv3 text.
- `/ios/` — create — blank Xcode SwiftUI app project.
- `/ios/LICENSE` — create — MIT text.
- `/android/` — create — blank Android Studio/Gradle Compose project.
- `/android/LICENSE` — create — MIT text.
- `/protocol/` — create — empty dir + `README.md` placeholder.
- `/protocol/LICENSE` — create — MIT text.

> **Rule for agent:** don't touch files outside this list without flagging it
> first.

## Interface / Data Contract

None — this slice creates project shells only. No schema or interfaces exist yet.

## Implementation Notes

- Desktop: use the current Tauri CLI's app-creation flow, selecting the Svelte +
  TypeScript template.
- iOS: minimum deployment target iOS 17 per the PRD's OS-version Decisions.
- Android: minimum API level not yet fixed (PRD Decisions defers this) — use
  whatever the scaffolding tool defaults to; don't hand-pick a number here.
- Each shell should build and run showing its own default/blank template screen —
  no customization.

## Definition of Done

- [x] `/desktop`, `/ios`, `/android`, `/protocol` exist per the EDD's repo layout.
- [x] Each has its correct `LICENSE` file.
- [x] Desktop Tauri app builds and launches, showing its default template screen.
- [x] iOS project builds and runs in Simulator, showing a blank screen.
- [x] Android project builds and runs in an emulator, showing a blank screen.

**Verification:**
```
cd desktop && npm install && npm run tauri dev
cd ios && xcodegen generate && xcodebuild -project Buttons.xcodeproj -scheme Buttons -destination 'platform=iOS Simulator,name=iPhone 17' build
cd android && ./gradlew assembleDebug
```
All confirmed on real hardware/simulators/emulator — desktop app window launched,
iOS app installed and screenshotted in Simulator, Android app installed and
screenshotted in a `medium_phone` AVD (android-36, google_apis_playstore/arm64-v8a).

> **Rule for agent:** run the verification command(s) above before declaring this
> slice done. Report the actual output, not an assumption that it passed.
